# 预注册协议:净签名期权流的 gamma-区制预测力(pilot)

- **状态**:预注册(pre-registered)· 起草 2026-07-18
- **性质**:signal research pilot,非策略回测。结论前**不改动本协议的假设与检验口径**(改动记入文末"修订记录",避免 p-hacking)。
- **一句话**:检验"净签名期权流的符号"是否预测**短周期收益的自相关方向**(空γ→延续、多γ→回归)。

---

## 1. 背景与边界(为什么只测这一个)

期权结构类指标(GEX / IV / skew / term / VRP / PCR / max-pain)的**历史值无法回溯重建**——greeks/OI/IV 链快照是快照专属,`gex_daily` 也只有起于 2026-07-14 的**每日一点**。唯一能用历史 trades+quotes **干净重建**的,是**每笔成交方向**。故本 pilot **只测净签名期权流**,不声称覆盖其它指标。

见 [CONTEXT.md](../CONTEXT.md) 术语「净签名期权流」——它是 flow-GEX 的**方向内核**,但**不是 flow-GEX**(缺 gamma×OI 权重)。

## 2. 研究问题与假设(预注册,方向性)

**RQ**:客户净买期权(→ dealer 空 gamma)是否使标的短周期收益更"延续";客户净卖(→ dealer 多 gamma)是否更"回归"?

- **H1(主)**:在 `S>0`(净买/空γ)分组,前向收益 `r_fwd` 与近期收益 `r_past` **正相关**;在 `S<0`(净卖/多γ)分组,**负相关**。即交互项 `β>0`。
- **H0**:两组自相关无差异,或交互项 `β` 不异于无条件基准。
- **方向已预注册**:只认 `β>0` 为"支持假设";`β<0`(反向)不得事后改述为"另一种胜利"。

## 3. 信号定义 S(精确、可重建)

- 对每票,取**近价 ±15% / ≤14DTE** 的合约,当日成交量 **top-40**。
- 每笔成交用 **Lee-Ready**(成交价 vs 成交**时刻**前最近 NBBO:≥ask=主动买,≤bid=主动卖,中价→tick 回退)判向,**size 加权**。
- **call 与 put 的主动买都记为"客户买"**(→ dealer 空γ);主动卖记为"客户卖"。**不分多空极性**(本 pilot 测 gamma 区制,非涨跌方向)。
- 累计到时刻 T 的净值 `net_T = Σbuy_size − Σsell_size`;`S_T = sign(net_T)`。**只用 ≤T 的成交**(前视纪律)。
- **不加 gamma 权重**(历史 gamma 拿不到)。这是与 flow-GEX 的核心差异。

## 4. 目标变量与检验

- `r_past = ret(T−30min → T)`,`r_fwd = ret(T → T+30min)`,用标的中间价/成交价对数收益。
- **市场中性化**:`r_fwd` 减去当日横截面均值(去大盘 beta),记 `r_fwd*`。
- **主检验(分层对照)**:
  1. 无条件基准:全样本 `corr(r_fwd*, r_past)`(日内本身的自相关)。
  2. 分组:`S>0` 组的 `corr₊`、`S<0` 组的 `corr₋`。
  3. **判定量 = `corr₊ − corr₋`(应 > 0)**,且相对无条件基准有分化。
- **等价回归**:`r_fwd* = α + β·(S·r_past) + γ·r_past + ε`,预注册看 `β>0`。

## 5. 窗口与采样

- **30 / 30 min,不重叠网格**(RTH 每日 ~12 点)。不重叠以减少前向窗口自相关。
- 稳健性(次要、单列,不作主结论):15/15、60/60 —— 报告但明确标注为 robustness,受多重检验影响。

## 6. 延迟处理(两版都跑)

- **信息上界版**:用成交时刻的流(重建无延迟)→ 测"信息是否存在"。
- **可交易版**:信号**滞后 15min**(期权数据实盘延迟)+ 小执行滞后 → 测"能否真的下手"。
- **两版差距 = 延迟吃掉的 alpha**,必须一并报告。

## 7. 样本与数据

- **票**:全单名股 ~19(排除 ETF:SPY/QQQ/SOXX —— 无 flow)。**按流动性分层**报告(AMD/TSLA/MU/COIN… 一组;AAOI/KLAR/SNDK 等稀成交小票单列,别混入主结论)。
- **区间**:pilot 首窗 = 最近 5 交易日;此后每交易日自动追加。
- **重建**:历史 trades(`/v3/trades`)+ quotes(`/v3/quotes`,`limit=5万` 通常 1-2 页)按时间戳归并做 Lee-Ready;top-40/票 × ~5 天 × ~19 票 ≈ 1 万调用,Actions 并发一次性。

## 8. 判定标准(功效受限下的诚实框架)

- **硬事实**:显著性的独立单元是"**天**"(同日内横截面相关)。一周 ≈ **5 个日块** → block-bootstrap-by-day 置信区间极宽 → **几乎必然不显著**。
- 故 **pilot 阶段不以显著性判定**,而看:
  1. **效应量**:`corr₊ − corr₋` 的大小(预注册"值得继续"阈值:**≥ 0.05** 且方向为正)。
  2. **方向一致性**:5 天里 `corr₊ − corr₋ > 0` 的天数(≥ 4/5 视为一致先验)。
  3. **两版对比**:可交易版是否仍保留部分效应(否则信号不可交易)。
- **正式结论(可信/丢弃)**:待累积到 **≥ 30–40 交易日**(≈6–8 周)后,用 block-bootstrap-by-day / 天聚类稳健 SE 做显著性,并对"2 版 × 主+2 稳健窗口"做**多重检验校正**(如 BH-FDR)。

## 9. 前向累积(walk-forward)

- 盘中采集每轮追加一条 `(t, sym, flow_net_sign, spot)` 到历史日志(扩展 `gex_history` 或新 `flow_history.json`),供本检验**每日自动重跑**、样本随时间增长。
- 协议脚本固化后,新数据进来**不改口径**,只是 N 变大。

## 10. 已知误差(结论必须带的限定)

1. **丢 gamma 权重** → 被高量低-gamma 的便宜虚值合约带偏;结论只推"期权流方向/gamma 区制",**不能当 flow-GEX 的结论**。
2. **开仓 vs 平仓无法区分**(历史无每日 OI delta):客户"买"可能是开多或空头回补。
3. **Lee-Ready 残差 ~10–20%**;中价单退回 tick;多腿单部分漏网。
4. **size ≠ 金额/信心**;`top-40` 覆盖有上限(coverage 误差,同实盘)。
5. **样本自相关**:即便不重叠,同日横截面相关 → 有效样本 ≪ 名义。

## 11. 分析冻结 / 什么会改变结论

- 本协议第 2–8 节在首次运行前**冻结**。运行后若需改口径,记入下方修订记录并**重跑全部历史**(不得只在有利子集上改)。

# 首轮结果与解读(2026-07-19,stakeholder 摘要)

## 一句话结论
按预注册标准,**假设未通过,且效应方向与预期相反**。但这是对**"裸期权流方向"这个代理指标**的判决,**不是对 flow-GEX 本身的判决**——最可能的原因是这个代理**丢掉了 gamma 权重**(已在诊断验证中)。**pilot 的价值在于:它用很小代价,阻止了我们在一个错误前提上开始建策略。**

## 来龙去脉(为什么这么做)

1. **目标**:在形成交易策略**之前**,先按业界实践验证"指标到底有没有预测力"(signal research → strategy,而非拍脑袋建策略)。首选验证我们判断价值最高的 **flow-GEX(期权资金流的 gamma 效应)**。

2. **一道硬约束逼我们缩小范围**:期权结构类指标(GEX / IV / skew / PCR / max-pain)是**快照专属**——历史上的 gamma、未平仓量(OI)、隐含波动率**无法回溯重建**,我们的记录也才起于 5 天前。历史上**唯一能干净重建**的,是**每笔成交的买卖方向**(用逐笔成交 + 买卖盘还原)。所以本轮**只能测"净签名期权流"这一个方向代理**,一周数据。

3. **方法(预注册,防作弊)**:检验前**先锁死假设与口径**(pre-registration,业界公认防 p-hacking 的做法)。
   - **信号**:近价合约的客户净买/净卖(Lee-Ready 判向)。
   - **假设**:客户净买期权 → 做市商被动"空 gamma" → 会**追涨杀跌、放大动量**(延续);客户净卖 → 做市商"多 gamma" → **抑制、均值回归**。
   - **检验**:短周期收益的**条件自相关**(延续 vs 回归),两版延迟(信息上界 / 可交易),剔除大盘同涨同跌,按流动性分层。

## 结果(19 只单名股 × 5 天,1140 个观测)

| 指标 | 预注册要求 | 信息上界版 | 可交易版 |
|---|---|---|---|
| 判定量 `corr₊ − corr₋` | **> 0 且 ≥ 0.05** | **−0.124** | **−0.250** |
| 交互项 β 符号 | **> 0** | −0.066 | −0.133 |
| 逐日方向一致 | **≥ 4/5** | 1/5 | 0/5 |

预期是"空 gamma 组更延续";**实测相反**——反而是"多 gamma 组"承载了动量,两版一致、逐日 0–1/5。

## 怎么正确解读(防止误读为"flow-GEX 没用")

- **这测的是流方向代理,不是实盘 flow-GEX**。它用重建的当日流方向,而非带真实 OI 种子的 flow-GEX。
- **诊断 B 已完成(gamma 近似加权)**:重跑一版**用 BS 近似 gamma 加权**(压制深虚合约 ~10×),判定量 **−0.149 / −0.270**(信息版/可交易版),逐日 0/5、1/5 —— **与裸流几乎一致,没有翻正**。

  → **重要:"反向"不是因为丢了 gamma 权重**。我们原以为是深虚高量合约把裸流带偏,但加权后结果不变 → **反向/无延续关系对 gamma 加权稳健**。病因指向别处:
  - **开仓 vs 平仓污染**(已知误差 #2):"客户买"可能是空头回补(平仓),那样并不真的让 dealer 空 gamma → 流符号与真实 gamma 区制脱钩。历史无每日 OI 变化,重建修不了这一层。
  - **假设本身可能不成立**:30min 日内、这一周、这批票上,"空 gamma → 延续"未出现(反而多 gamma 组带动量)。可能是**本周单一 regime**,也可能机制在更长/更短周期才显现。
  - **功效**:仍是 5 日块,不能排除是本周的噪声/特例。

## 诚实的统计声明(不夸大)
- 一周 ≈ **5 个独立"交易日块"**,统计功效几乎为零 → 以上是**效应量/方向的先验**,**不是显著性结论**(我们预注册就承诺不拿一周数据宣称显著)。
- 但"两版都反向 + 逐日 0–1/5 一致",足以把"裸流符号预测延续"这个直觉**降为低可信**。

## 结论与下一步
1. **不要**在"跟随期权流方向做延续"这个信号上建策略——裸流**和** gamma 加权版本本周都给出反面先验。
2. **诊断 B 已排除"丢 gamma"这个便宜解释**:加权后判定量不变 → 反向对 gamma 加权稳健。剩余最可能病因是**开/平仓污染**(流方向≠持仓方向)与**假设本身在本周日内不成立**。
3. **要测真正的 flow-GEX,便宜路已走完,只能靠前向累积**:让盘中采集每轮记录①带**真实 OI 种子**的 flow-GEX 净值、②**每日 OI 变化**(区分开/平仓)、③前向收益;攒 **6–8 周(≥30-40 交易日)+ 跨不同 regime** 后用同一套预注册检验重跑。
4. **策略化**只在某个信号**通过**验证之后才启动。

**给 stakeholder 的一句话**:我们不仅测了期权流方向、还额外做了 gamma 加权诊断以**排除最明显的数据假象**——两者都显示"跟随期权流做延续"本周**不成立**。这不是浪费:它用一周的小成本挡住了一个错误策略,并锁定了下一步要修的真问题(开/平仓 + 更长样本)。方法论(预注册/前视纪律/分层/诚实功效)可复用到任何后续指标。

> 方法论本身是这轮最大的资产:预注册 + 前视纪律 + 分层对照 + 诚实的功效声明 + 可复现脚本(`scripts/backtest_flow_gamma.py`),后续任何指标都能套这套流程跑。
