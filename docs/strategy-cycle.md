# 策略操作周期(周节奏)

- **状态**:流程框架。**当前无任何已通过验证的信号**(见 [backtest-flow-gamma-pilot.md](backtest-flow-gamma-pilot.md))→ 过渡期的周二三交易是**基于指标的 discretionary(相机)交易**,不是系统化 edge。本文档定义**怎么运转**与**信号如何毕业成规则**,不是投资建议。
- **节奏**:一周一个策略周期;**周二、周三为主交易日**。

---

## 0. 两条铁律(先立规矩)

1. **过渡期 = 小仓 + 严纪律 + 边做边攒数据**。指标未验证,交易目的一半是练执行、攒样本,不是押注一个"已证明的优势"。仓位小到"错了也不影响下周"。
2. **信号毕业门**:任何指标要从"报告里的解读"升级成"策略规则",必须先过 [pilot](backtest-flow-gamma-pilot.md) 验证(≥30-40 交易日 + 显著性 + 多重检验)。**没过 = 只能相机参考,不能写成机械规则**。

## 1. 周节奏

| 日 | 角色 | 主要动作 | 用的工具 |
|---|---|---|---|
| **周一** | **周期启动 / 定 thesis** | 跑全 watchlist 分析报告 → 选本周 3-5 只候选 → 每只写下 **thesis + 触发位 + 失效位 + 目标位**;不交易或极轻 | `gen_report.py` / [analysis_report_playbook.md](analysis_report_playbook.md) |
| **周二–周三** | **主交易** | 只做周一定下的候选;盘中择时进出;**触发位进、失效位无条件出** | 交易台(K线/GEX/flow/VWAP/行权价梯) |
| **周四** | **减仓 / 兑现** | 临近周五 opex + gamma 到期,降 pin 风险;评估 thesis 是否走完,不恋战 | 交易台 + `maxpain_pin` |
| **周五** | **opex + 复盘** | opex 日只管理已有仓位(不新开);盘后复盘本周 | 复盘模板(见 §4) |
| **贯穿全周** | **攒样本** | 前向记录器每轮累积 `flow_history.json`;每 6-8 周用 pilot 重估信号 | `fetch_research.py` / `eval_flow_history.py` |

## 2. 周一:定 thesis 的最小结构(每只候选)

- **方向/场景**:偏多 / 偏空 / 区间,及理由(哪几个指标共振)。
- **关键位**(全部来自报告,不拍脑袋):上方阻力(gamma 墙/flip)、下方支撑(max-pain/负 gamma 加速带)、预期振幅区间。
- **触发位**:什么价/什么条件才进(不满足就不碰)。
- **失效位**:碰到就无条件离场的价(**先于进场就写死**,防止盘中改主意)。
- **max-pain pin 参考**:`pin` 分数 <20 忽略、>45 才当磁吸目标(未校准,仅参考)。
- **数据质量标注**:IV 是否疑近月失真、flow coverage 高低、财报临近否——低质量的直接降权或跳过。

## 3. 风控(过渡期从严)

- **单票失效位**:周一写死,盘中只能收紧不能放宽。
- **周损失上限**:触及即停手到下周一(具体数额自定)。
- **周四后不新开**、周五 opex 不新开——只管理。
- **仓位**:过渡期显著小于"验证后"的规模;分散,不押单票。
- **禁区**:财报当周(IV crush)、`flow` coverage 极低、IV 疑失真的票,不作为机械依据。

## 4. 周五复盘(喂回验证闭环)

每只交易过的票记:thesis 对不对、失效位是否触发、**赢/亏的真实原因**(是指标对了,还是运气/大盘)。汇总本周:
- 哪些指标的解读**兑现**、哪些**打脸** → 更新对指标的先验。
- 复盘结论**不改 pilot 的预注册口径**,只作为定性观察;信号是否有效仍以 pilot 的量化结论为准。

## 5. 信号毕业机制(discretionary → systematic)

```
指标在报告里被解读  →  纳入 pilot 前向累积(flow_history 等)
   →  攒 ≥30-40 交易日  →  eval 跑预注册检验 + 显著性/多重检验校正
      →  通过:写成机械规则(触发/失效/仓位),进入本周期的"系统化"部分
      →  不通过:留在"相机参考",或丢弃
```
在有信号毕业之前,§1 的周二三**全部是相机交易**,§3 风控从严。

## 6. 与现有系统的关系

- **信息页 / 交易台**:周一选票 + 周二三择时的界面。
- **分析报告(playbook)**:周一 thesis 的输入。
- **pilot + 前向记录器**:信号验证与毕业的后台,决定什么时候能把"相机"变"机械"。
- 本文档是**操作层**,不改数据/指标口径。
