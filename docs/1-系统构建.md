## 已知运维问题(debug list)
- **GitHub 定时不可靠**:`schedule` cron 常延迟(1.5-2h)或丢触发 → 盘中采集有时开盘后很久才起,甚至要手动。缓解:加错开 cron / 外部触发器(未做)。
- **Reddit 429**:每次采集必现——OAuth 未配 → 匿名 JSON 被拒 → 回退 RSS(丢点赞/评论数)。根治:配 `REDDIT_CLIENT_ID/SECRET`。
- **期权额度 50/min**:期权端点(链快照 + 逐笔)共用;并发/精确层需控节奏(见 [3-数据与存储](3-数据与存储.md) 调用量约束)。
