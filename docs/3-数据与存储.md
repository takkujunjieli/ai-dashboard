# 3. 数据与存储

数据源、采集节奏、调用量约束、存储布局与统计累积器的归类入口。

## 数据源
- **Massive**(原 Polygon 系):股票快照 / K线 / 期权链快照 / 逐笔成交 / 逐条 NBBO / short / 新闻。主源。
- **Finnhub**:行情、EPS、分析师评级、财报日历。
- **RSS / Reddit(OAuth)**:新闻、社区。

## 采集节奏(刷新频率)
| 数据 | 频率 |
|---|---|
| K线 1m/5m/15m、期权链、GEX(名义 + 采样 flow) | **每轮 ~2.5min**(盘中滚动采集;并发预取) |
| 指标(RSI/EMA,本地算)| 每轮 |
| 日线 / short / 新闻 | 每小时(低频层) |
| flow-GEX 精确层(top-N 逐笔 Lee-Ready) | 2×/天:盘中 **ET 12:00** 后首轮(`collect_session`,`PRECISE_HOUR`)+ **收盘后 ~15min**(`update.yml` cron `15 21 UTC`,`FLOW_PRECISE=1`);盘前那次已废(测不到今天)。tape 按 `timestamp.gte=当日` 抓 |
| EOD 基线 + 行情/信息流 | 1×/天(收盘后 update.yml) |
- 期权源本身 **~15min 延迟**;K线 Massive 实时(雅虎回退)。

## 调用量约束(全表见 [CONTEXT.md](../CONTEXT.md))
- **期权 50/min**(链快照 + 逐笔共用)。降负载:①期权只取现价 **±20%** 行权价 + ≤45 天;②RSI/EMA 本地算;③并发预取 + top-N 精确层控节奏。
- REST 500/min。GitHub contents API:匿名 60/时、PAT 5000/时。

## 存储布局
- **data 分支**:高频数据(每轮提交)推 data 分支,隔离 main 的 git 体积;每周压平(force-push 单提交)。**main 仅 EOD 基线**,作前端限流兜底。前端主读 data 分支(`?ref=data`)。
- **data/*.json 清单**:

| 文件 | 用途 | 留存 |
|---|---|---|
| `research.json` | 每票快照/指标/期权汇总/日线 | 覆盖(最新) |
| `bars_intraday.json` | 高频 K线(1m/5m/15m,拆出以控 research 体积) | 各粒度 keep 上限 |
| `gex.json` | 当次 GEX 快照(名义 + flow,by_strike/buckets/flip) | 覆盖 |
| `gex_history.json` | 当日盘中净 GEX 序列(sparkline) | **隔日清空** |
| `gex_daily.json` | 每(日,票)一条:GEX/PCR/IV/skew/vrp/maxpain_pin… | **250 天**(分位 + 回测) |
| `flow_history.json` | 每轮每票:真 flow-GEX + 名义 net + OI + spot | **60 天**(pilot 前向,见 [2-交易策略](2-交易策略.md)) |
| `oi_panel/{date}.parquet` | EOD 全链面板:近价≤14DTE 每合约 `sym,exp,strike,cp,oi,vol,gamma,delta,iv,mid,active_net`(按日分区) | **500 天**(离线 ΔOI×vol 开/平仓四象限;别人买不回来的前向历史) |
| `flow_accum.json` | 当日采样流累积器(buy/sell/flat) | 隔日重置 |
| `flow_precise.json` | 当日 top-N 逐笔精确签名(复用) | 隔日重置 |
| `oi_prev.json` | 上次各合约 OI(算跨轮/跨日 OI 变化) | 覆盖 |
| `market.json` / `feeds.json` | 行情/EPS/评级/财报 · 信息流 | 覆盖 |

## 数据质量与已知误差(2026-07-20 更新)

按对交易判断的影响排序。状态标签:**🟡 in review**(部分解决,验证/收尾中)· **🔴 open**(未动)· **⚪ 固有**(上游/机制决定,改不了,只能标注)。

### A. flow-GEX(Real / sampled)—— 是估计,不是真值 · 🟡 in review
**状态**:ambiguity 中价兜底已上线(`63ba03a`),待 07-21 盘中采集验证;coverage 已确认充分(中位 95%);开/平仓污染由**前向 `oi_panel` 面板 + 离线 ΔOI×vol 对账**解决(见下 A 段末)。
- **开/平仓污染(固有,最根本)**:采样/逐笔只判"主动买 vs 卖",分不清开仓还是平仓。dealer gamma 库存变化 = Σ sign×gamma×**ΔOI**,而净主动流 ≠ ΔOI。Massive **无 open/close 标记、无历史 OI**,无法回溯。pilot 已实证净流方向对 gamma 区制延续预测力**为负**(见 [backtest-flow-gamma-pilot](backtest-flow-gamma-pilot.md))→ **Real 符号只当结构参考,不当交易信号**。
  - **解法(前向)**:每日 EOD 存 `oi_panel/{date}.parquet` 全链面板,离线 **跨日 ΔOI 对账当日 vol**:ΔOI 同号≈vol → 净开仓;vol≫\|ΔOI\| → 日内对倒/平仓(主动净流假信号);ΔOI<0 → 净平仓。**ΔOI 就是 dealer 净库存变化本身**(非其代理),绕开开/平仓污染。攒够样本后可正式回测 gamma 库存方向的延续/反转预测力,若成立即可摘掉本 ⚪ 标记。
- **coverage 不是问题**:实测(EOD 2026-07-20)**84-100%,中位 95%**(gamma 加权、合约级)。追到 100% 只是补低 gamma 尾巴,对 net GEX 边际贡献≈0。
- **ambiguity 才是主要噪声源**:实测 **~40-44%**(成交量级,中价/脏价差判不出向的占比)。高覆盖但每个符号只由约 60% 成交量投票定。**已改进**:2026-07-20 起 `snapshot_side`(采样)与 `classify_lee_ready`(精确)的 quote rule 加**中价兜底**(触碰不变,价差内 >中价买/<中价卖,只剩正好中价算歧义;commit `63ba03a`)→ 预计显著降 ambiguity 且无 tick delta 污染。**待 07-21 盘中采集后验证**(定时任务 `check-flow-ambiguity-midpoint`)。
- 其余固有残差:Lee-Ready ~80-90%;`size ≠ notional`(张数非金额,便宜虚值合约带偏);`spread/mid > 0.25` 脏价差丢弃;band(±15%)外、>14DTE 合约全退回 Raw 假设符号(coverage 分母只算近价带,**全链 Real 占比比 95% 更低**)。

### B. GEX 口径(Raw vs Real)· 🟡 in review
**状态**:Raw/Real 双口径 + UI 区分已上线,单名股默认看 Real;残留是 Raw 符号本身的 ⚪ 固有偏差(靠 Real 覆盖,非全链)。
- **Raw (index) 的 call+/put− 符号假设对指数(SPX/SPY)校准、对单名股常错**(散户买 call → dealer 反而空 call)→ 单名股看 **Real**;墙的**位置结构**两者都可用,不可信的只是 Raw 的 **+/− 符号**。详见 [CONTEXT.md](../CONTEXT.md) 「GEX 口径」。

### C. %ADV · 🟡 in review
**状态**:ADV 已换 EWMA(20)(修滞后);ETF 隐藏/改标 %ADV 仍 🔴 待做。
- **ETF 语义失真(固有)**:SPY/QQQ 的指数 gamma 主要在 **ES/NQ 期货**对冲(指数买不到实物、期货保证金杠杆 + 免借券 + 近 23h),**不落在 ETF 股份成交上**。拿 SPY 股份 ADV 当分母是**用错了市场** → ETF 的 %ADV 数字公式对、含义无效。单名股才有"股票端冲击"意义。**可改进**:ETF 隐藏/改标(要算须换期货量分母)。
- ADV 已用 **EWMA(20)** 替代滞后 ~3 周的 `short.avg_daily_volume`。

### D. 新鲜度/时效 · ⚪ 固有为主
- 期权源 **~15min 延迟**;盘中 GEX 是延迟快照。**固有**。

- flow 精确层 **2×/天**,盘中不刷;采样层每轮刷但精度低。
