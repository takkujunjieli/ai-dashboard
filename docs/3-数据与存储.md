# 3. 数据与存储

数据源、采集节奏、调用量约束、存储布局与统计累积器的归类入口。

## 数据源
- **Massive**(原 Polygon 系):股票快照 / K线 / 期权链快照 / 逐笔成交 / 逐条 NBBO / short / 新闻。主源。
- **Finnhub**:行情、EPS、分析师评级、财报日历。
- **RSS / Reddit(OAuth)**:新闻、社区。

## 采集节奏(刷新频率)
| 数据 | 频率 |
|---|---|
| K线 1m/5m/15m、期权链、GEX(名义 + 采样 flow) | **每轮 ~2.5min**(盘中滚动采集;并发预取) |
| 指标(RSI/EMA,本地算)| 每轮 |
| 日线 / short / 新闻 | 每小时(低频层) |
| flow-GEX 精确层(top-N 逐笔 Lee-Ready) | 2×/天(update.yml,`FLOW_PRECISE=1`) |
| EOD 基线 + Pages 部署 | 2×/天(update.yml) |
- 期权源本身 **~15min 延迟**;K线 Massive 实时(雅虎回退)。

## 调用量约束(全表见 [CONTEXT.md](../CONTEXT.md))
- **期权 50/min**(链快照 + 逐笔共用)。降负载:①期权只取现价 **±20%** 行权价 + ≤45 天;②RSI/EMA 本地算;③并发预取 + top-N 精确层控节奏。
- REST 500/min。GitHub contents API:匿名 60/时、PAT 5000/时。

## 存储布局
- **data 分支**:高频数据(每轮提交)推 data 分支,隔离 main 的 git 体积;每周压平(force-push 单提交)。**main 仅 EOD 基线**,作前端限流兜底。前端主读 data 分支(`?ref=data`)。
- **data/*.json 清单**:

| 文件 | 用途 | 留存 |
|---|---|---|
| `research.json` | 每票快照/指标/期权汇总/日线 | 覆盖(最新) |
| `bars_intraday.json` | 高频 K线(1m/5m/15m,拆出以控 research 体积) | 各粒度 keep 上限 |
| `gex.json` | 当次 GEX 快照(名义 + flow,by_strike/buckets/flip) | 覆盖 |
| `gex_history.json` | 当日盘中净 GEX 序列(sparkline) | **隔日清空** |
| `gex_daily.json` | 每(日,票)一条:GEX/PCR/IV/skew/vrp/maxpain_pin… | **250 天**(分位 + 回测) |
| `flow_history.json` | 每轮每票:真 flow-GEX + 名义 net + OI + spot | **60 天**(pilot 前向,见 [2-交易策略](2-交易策略.md)) |
| `flow_accum.json` | 当日采样流累积器(buy/sell/flat) | 隔日重置 |
| `flow_precise.json` | 当日 top-N 逐笔精确签名(复用) | 隔日重置 |
| `oi_prev.json` | 上次各合约 OI(算跨轮/跨日 OI 变化) | 覆盖 |
| `market.json` / `feeds.json` | 行情/EPS/评级/财报 · 信息流 | 覆盖 |

## 统计累积器(供回测/分位)
- `gex_daily`:PCR/IV 自身历史分位、Max Pain pin 回测(见 [2-交易策略](2-交易策略.md) #7)。
- `flow_history`:flow-GEX 预测力 pilot 的前向样本(#8)。
